# CareersHub - Professional Job Portal Application

CareersHub is a production-grade, full-stack Job Portal web application. It features a modern React UI integrated with a secure Spring Boot REST API backend powered by MySQL.

## Key Features

- **Authentication & Authorization**: Secure JWT-based authentication system with BCrypt password hashing. Role-Based Access Control (RBAC) supports three roles: `JOB_SEEKER`, `EMPLOYER`, and `ADMIN`.
- **Dynamic Search & Filters**: Search jobs by keyword, location, job type (Full-time, Part-time, Contract, Remote), experience level, and minimum salary, backed by dynamic Spring Data JPA queries.
- **Job Seeker Features**: Build and edit profile details, upload resumes, view listings, apply to jobs (with dual-application prevention), and track application status.
- **Employer Features**: Manage company profiles, upload logos, post jobs, edit/delete job postings, view candidates who applied to their jobs, and update candidate application statuses.
- **Admin Control Panel**: View, manage, and delete registered users and job listings across the platform.
- **File Server Service**: Secure local multi-part file uploads for candidate resumes (PDFs) and company logos.

- **Styling**: Premium Vanilla CSS design system with custom HSL tokens, dark mode gradients, glassmorphism, responsive grid layouts, and micro-animations
- **Routing**: React Router DOM (v6)
- **Icons**: Lucide React

## System Configurations & Setup

### 1. Database Setup
Ensure you have MySQL server running locally. Create the database named `job_portal_db`:
```sql
CREATE DATABASE job_portal_db;
```
Configure your connection properties in [application.properties](file:///c:/Users/MARI%20ANANTH/OneDrive/Desktop/google/job%20portal/backend/src/main/resources/application.properties):
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/job_portal_db?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=root2004
spring.jpa.hibernate.ddl-auto=update
```

### 2. Launch Backend Application
Navigate to the `backend` folder and run the Maven Spring Boot plugin:
```powershell
# In PowerShell (Backend folder)
.\mvnw.cmd spring-boot:run
```
The server will start up on **`http://localhost:8080`**. Database tables will be automatically generated by Hibernate on first startup.

### 3. Launch Frontend React app
Navigate to the `frontend` folder, install required packages, and start the development server:
```bash
# In npm (Frontend folder)
npm install
npm run dev
```
The application will boot on **`http://localhost:5173`**.

## Testing & User Roles

To test the role-based flows:

1. **Register as Job Seeker**:
   - Sign up on the Register page.
   - Go to Profile, input skills, bio, education, and upload a test **PDF resume** (max 5MB).
   - Go to "Find Jobs", search, view details, and click "Apply Now".

2. **Register as Employer**:
   - Toggle to "Employer" on the Register page. Fill in primary contact, company name, and location.
   - Navigate to "Company Profile" to upload a logo and details.
   - Go to "Post a Job" to publish a new listing.
   - Under "My Jobs", click "Applicants" to see candidates who applied and change their status via the dropdown.

3. **Log in as Admin**:
   - Register a user with email `admin@careershub.com` (configured as Admin role in default mock filters, or update a user's role to `ADMIN` in the database).
   - Toggle between tabs to delete users or listings.
